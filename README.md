#CellScan V1
A battery cell tester built on the Raspberry Pi Pico W.
It will measure voltage, current, temperature and internal resistance, then grade a cell as A, B or C.
Status: just started (Nov 2026). Simulating in Wokwi first, then building real hardware.

## Blink LED
MicroPython blink code for Raspberry Pi Pico, in `simulation/blink.py`.
`simulation/machine.py` is a stand-in so the code runs on a normal PC.
